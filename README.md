# Warehouse Inventory Dashboard

A modern, responsive, and static single-page dashboard designed for warehouse inventory tracking and stock management. This project was developed to implement and solidify fundamental Bootstrap 5 components without writing complex custom CSS.

## 🚀 Key Features

- **Data Pagination:** Implemented a structured and clean Bootstrap **Pagination** component to effectively navigate through long lists of warehouse products, ensuring a user-friendly data presentation.
- **Responsive Grid Layout:** Fully responsive design utilizing the Bootstrap grid system, ensuring seamless adaptation across mobile (stacked), tablet, and desktop screens.
- **Visual Status Indicators:** Strategic use of Bootstrap Badges, Progress bars, and contextual background colors to display real-time stock health (In Stock, Low Stock, Out of Stock).
- **Simulated Interactive Components:** Integration of Alerts for critical stock warnings and Spinners to simulate server synchronization processes.
- **Modern Table Design:** A clean, striped, and hoverable data table optimized for responsive viewing, dynamically hiding certain columns on smaller mobile devices.

* [Bootstrap Icons](https://icons.getbootstrap.com/) - Modern iconography for the UI
